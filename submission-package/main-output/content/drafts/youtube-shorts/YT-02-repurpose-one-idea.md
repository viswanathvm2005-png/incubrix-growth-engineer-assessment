# YT-02 — Repurpose One Idea

**Platform:** YouTube Shorts
**Asset type:** Short video script
**Target duration:** 30–45 seconds; final edit must be 60 seconds or less
**Status:** Draft — NOT approved or published
**Audience:** Creators, editors, and small content teams
**Content category:** Educational creator workflow

## 1. Opening hook
One idea can become more than one post.

## 2. Voiceover script
Start with one useful idea your audience cares about. Explain it in a short video. Turn the key steps into a carousel. Write a text post with the main lesson. Then create a checklist people can save. Keep the core message consistent, but adapt the format to each platform.

## 3. Visual and editing instructions
Show one central idea branching into a Short, carousel, text post, and checklist.

Use original visuals or assets with documented usage permission. Keep text readable on a mobile screen. Use accurate captions and review the final cut for context and accessibility.

## 4. On-screen text
ONE IDEA
FOUR FORMATS
ADAPT EACH VERSION

## 5. YouTube description / caption
Repurposing means adapting a useful idea, not copying the same post everywhere. Start with one idea and give each format a clear purpose.
