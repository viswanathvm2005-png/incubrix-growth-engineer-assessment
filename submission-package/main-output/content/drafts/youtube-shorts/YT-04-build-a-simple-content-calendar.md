# YT-04 — Build a Simple Content Calendar

**Platform:** YouTube Shorts
**Asset type:** Short video script
**Target duration:** 30–45 seconds; final edit must be 60 seconds or less
**Status:** Draft — NOT approved or published
**Audience:** Creators, editors, and small content teams
**Content category:** Educational creator workflow

## 1. Opening hook
Your content calendar does not need to be complicated.

## 2. Voiceover script
Start with five columns: date, topic, format, status, and call to action. Add your ideas before assigning dates. Mark each item as a draft, in review, or ready. Leave room to adjust when priorities change. The goal is to make the next action visible, not to build a complicated spreadsheet.

## 3. Visual and editing instructions
Build a clean five-column calendar and show a draft moving through review.

Use original visuals or assets with documented usage permission. Keep text readable on a mobile screen. Use accurate captions and review the final cut for context and accessibility.

## 4. On-screen text
DATE | TOPIC | FORMAT
STATUS | CTA

## 5. YouTube description / caption
A practical content calendar starts with a few useful fields. Add complexity only when your workflow genuinely needs it.
