## Post copy
A useful opening does not need to shout. It needs to help the right reader recognise why the post matters.

Try this simple edit:

Broad: "Here are some video tips."

More specific: "Planning your next YouTube video? Start by writing down the one lesson viewers should remember."

The second example names a situation and previews a useful action. It does not promise a result that has not been demonstrated.

Before publishing, ask:
- Who is this for?
- What question does it address?
- What will the reader learn?

## Caption
The first line sets expectations. Make it specific enough to orient the reader, then deliver the value promised by the hook.
