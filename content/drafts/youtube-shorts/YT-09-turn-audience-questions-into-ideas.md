**Platform:** YouTube Shorts

## 1. Opening hook

## 2. Voiceover script
Start with questions your audience actually asks. Group similar questions into themes. Pick one question you can answer accurately. Give the answer in a short video, then use the supporting steps for another format. Protect private information, and do not assume one question represents everyone's needs.

## 3. Visual and editing instructions
Show anonymised example questions grouped into themes, then select one for a video.

Use original visuals or assets with documented usage permission. Keep text readable on a mobile screen. Use accurate captions and review the final cut for context and accessibility.

## 4. On-screen text

GROUP THEMES
ANSWER ONE WELL

## 5. YouTube description / caption
Audience questions can inspire useful content. Use appropriate, permission-safe sources and avoid exposing private messages.
